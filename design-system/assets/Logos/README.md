The Homeboard logo: a marigold roofline over an aubergine board with a 3×2 week, today lit marigold (center-bottom) and one fern cell on the diagonal (top-right). Wordmark: Rubik ExtraBold, outlined, lowercase.

- `logo.svg`: horizontal lockup for light grounds. Tile `#3d1f3a`, roof and today `#f2b22e`, fern `#6f9460`, board `#f6f5f0`, wordmark `#3d1f3a`.
- `logo-on-dark.svg`: no tile; board `#f6f5f0`, cells `#1c1320`, wordmark `#f3eef2`. For night grounds only.
- `logo-stacked.svg`, `logo-stacked-on-dark.svg`: mark above name, for square spaces.
- `mark.svg`, `mark-on-dark.svg`: the symbol alone; 16px minimum.
- `logo-mono.svg`, `mark-mono.svg`: single ink `#2a1a28`, cells knocked out.
- `app-icon.svg`: full-bleed aubergine square for PWA and home-screen icons.
