# PersonTag

A household member or player: a colored dot + name.

- **Consumer provides:** name and one of the eight `person-*` colors (chosen in admin).
- **Use:** to-do assignees, calendar event owners (as a 3px bar), scorecard player names.
- **On solid red or marigold cards** the dot and name take the card's text color.
- **Don't:** wrap it in a tinted chip, or use marigold, red or aubergine as a person color.
