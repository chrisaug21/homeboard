# Eyebrow

The screen-type pill that starts every display screen.

- **Use:** top-left of each display screen, one per screen.
- **Consumer provides:** a 17px line icon and a short label (1-3 words).
- **Style:** `eyebrow-bg` fill, `eyebrow-fg` icon and text, `label` type (uppercase, 0.1em tracking), `tag-radius`.
- **Don't:** use it as a filter chip or button, or recolor it per screen.
