# NavBar

The display footer: logo, screen tabs, sync status.

- **Consumer provides:** the enabled screens in order and the active one.
- **Style:** tabs are `card` with `muted` icons; the active tab is `primary` / `on-primary` and 10px wider. Logo bottom-left (`logo.svg` in Light, `logo-on-dark.svg` in Dark) about 22px tall; sync label in `caption`, `muted`. (The preview sets the name in type as a stand-in for the logo file.)
- **Don't:** add labels under icons or badge counts.
